# 🏥 Healthcare Operations & Performance Analytics Dashboard

An end-to-end data analytics and business intelligence project built using **Microsoft Excel (Power Query, Pivot Tables, and VBA)** to process, clean, and analyze 16,656 healthcare visit records.

---

## 📊 Project Overview
This project transforms raw, inconsistent healthcare transactional data into a pristine, structured dataset to evaluate patient demand, financial channels, scheduling compliance, and departmental performance.

## 🛠️ Tools & Technologies Used
* **Data Cleaning & ETL:** Power Query (Excel)
* **Data Modeling & Aggregation:** Pivot Tables & Pivot Charts
* **Automation:** VBA / Macro (`Reset Filters` button)
* **Visualization:** Custom Dark-Theme Executive Dashboard

---

## 💡 Key Analytical Insights
1. **Departmental Demand:** Patient volume is heavily concentrated in **Cardiology** (1,587 visits / 12.2%) and **Dermatology**, requiring priority staffing.
2. **Financial Preferences:** Transactions show an even split across **Credit Card (24.4%)**, **Cash (23.9%)**, **Insurance (23.7%)**, and **Debit Card (23.0%)**, with digital payments totaling **47.4%**.
3. **Care Continuity:** The average time gap between initial visits and follow-up consultations is **33 days**.
4. **Seasonal Surge:** Patient intake peaks consistently in **Q4** across operational years.

---

## 🚀 Strategic Recommendations
* **Capacity Planning:** Align clinical staffing and room allocation with Q4 peak surges and high-demand specialties (Cardiology & Dermatology).
* **Billing Optimization:** Expand electronic POS card terminals across outpatient clinics to support the 47.4% digital payment volume.
* **Follow-Up Efficiency:** Deploy automated SMS/email reminders prior to the 33-day follow-up mark to minimize no-shows.
